# moko

Android photo editing MVP focused on transforming an existing gallery photo into a specific camera-style look.

The first product priority is a high-quality Flash look:

```text
Select photo -> Apply Flash -> Compare Before / After -> Save
```

## Current Sprint

Sprint 0 - Project Setup

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Single Activity
- MVVM / UDF
- StateFlow
- Coroutines
- Hilt
- Navigation Compose
- Android Bitmap / ImageDecoder
- MediaStore
